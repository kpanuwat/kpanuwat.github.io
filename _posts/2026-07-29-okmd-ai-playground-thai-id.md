## TL;DR

**OKMD AI Playground** (`playground.okmd.or.th`) คือแพลตฟอร์มจากภาครัฐไทย ให้คนไทยทุกคน "เล่น AI" ฟรีผ่านการยืนยันตัวตนด้วย **ThaiD** หรือบัญชี TK Park/OKMD e-member — รวม AI ชั้นนำอย่าง Gemini, GPT, Claude (Sonnet), DeepSeek, Grok ไว้ในหน้าเดียว พร้อมฟีเจอร์สร้างเว็บแอป (deploy ได้จริง), Text-to-Speech, สร้างภาพ, และ API key สำหรับนักพัฒนา — โควตาให้เปล่าราวๆ 350,000 token/วันต่อโมเดล (ตัวเลขขึ้นกับโมเดล)

## Background / Why this matters

**OKMD** หรือ สำนักงานบริหารและพัฒนาองค์ความรู้ (องค์การมหาชน) เป็นหน่วยงานรัฐไทยที่ดูแลเรื่องการเรียนรู้ตลอดชีวิต (lifelong learning) — เจ้าของ TK Park (อุทยานการเรียนรู้) ก็อยู่ในเครือนี้ วันที่ 1 พฤษภาคม 2569 OKMD เปิดตัว 3 บริการใหม่พร้อมกัน ได้แก่ **OKMD AI Playground** (รวม AI หลายค่ายไว้ทดลองใช้), **OKMD Knowledge Portal** (digital library เชิงลึก), และ **OKMD Corporate** (ยกระดับทักษะบุคลากร) [4] — บทความนี้เจาะเฉพาะ **AI Playground** ซึ่งเป็นตัวที่คลิปต้นทางพูดถึง

ประเด็นที่ทำให้เรื่องนี้น่าสนใจกว่าข่าวเปิดตัวทั่วไป: ค่าใช้จ่ายพัฒนาแพลตฟอร์มนี้อยู่ที่ราว **2.4 ล้านบาท** (บวก token cost อีกราว 500,000 บาท) เทียบกับโครงการ **TH-AI Passport** ของหน่วยงานอื่นที่ได้งบ **1,621 ล้านบาท** สำหรับภารกิจใกล้เคียงกัน — ส.ส. บวรศักดิ์ พงศ์วิทยาพันธุ์ ตั้งคำถามในสภาถึงความคุ้มค่า โดยระบุว่า TH-AI Passport มีผู้ใช้งานจริงเพียงราว 100 คน/ชั่วโมง [6] เรื่องนี้จึงเป็นทั้งข่าวดี (คนไทยมีของฟรีใช้จริง) และเคสศึกษาเรื่องงบประมาณภาครัฐไปพร้อมกัน

## Deep Dive

### โมเดล AI ที่มีให้เลือกใช้

จากการตรวจสอบทั้งเว็บข่าวและวิดีโอสาธิตจริงในระบบ พบว่า Playground รวมโมเดลมากกว่า 10 ตัวจากหลายค่าย [5][10]:

| ค่าย | โมเดลที่พบในระบบ |
|------|------------------|
| Google | Gemini (รุ่น 3.5 Flash ที่สาธิตในคลิป) |
| OpenAI | GPT |
| Anthropic | Claude (Sonnet 5) |
| DeepSeek | DeepSeek |
| xAI | Grok |
| Meta | Meta AI |
| Perplexity | Perplexity |
| อื่นๆ | Typhoon (โมเดลไทยจาก SCB 10X) และโมเดลเพิ่มเติมผ่าน model router |

จุดเด่นคือฟีเจอร์ **Compare & Contrast** — พิมพ์คำสั่งครั้งเดียว แล้วดูคำตอบจากหลายโมเดลพร้อมกันในหน้าจอเดียว เหมาะกับคนที่ยังไม่รู้ว่าจะ "ปักหลัก" กับโมเดลไหน [1][5]

### ฟีเจอร์ที่ทดสอบจริงในคลิปสาธิต

วิดีโอต้นทางสาธิตให้เห็นว่าฟีเจอร์เหล่านี้ใช้งานได้จริง ไม่ใช่แค่คำโฆษณา [1]:

- **สร้างเว็บแอปพลิเคชัน** — สั่งให้ AI เขียนโค้ดเว็บไซต์ (ตัวอย่างในคลิป: เว็บร้านกาแฟ) แล้วกดปุ่ม **deploy** มุมขวาบนเพื่อรันทดสอบบน Playground ได้ทันที ดาวน์โหลด source code ไปใช้งานจริงต่อได้ด้วย
- **Text-to-Speech (TTS)** — สั่ง AI สร้างเว็บอ่านออกเสียงภาษาไทย มีปุ่มเล่นเสียง ปรับความเร็ว และดาวน์โหลดเป็น MP3
- **สร้างภาพ (Image Generation)** — ทดสอบด้วย Gemini 3.5 Flash สร้างภาพปกวิดีโอ YouTube ตามกฎ 3 ส่วน (rule of thirds) พร้อมใส่ข้อความขนาดใหญ่ในภาพ
- **API Key สำหรับนักพัฒนา** — มี API key ให้เชื่อมต่อเข้าแอปพลิเคชันของตัวเอง สาธิตการยิง request ผ่าน `curl` ตรงในคลิป

### โควตา token รายวัน

ระบบนับ input + output token รวมกัน จำกัดเป็นรายวันต่อโมเดล — ตัวอย่างจากคลิป: โมเดล Gemini ให้โควตาประมาณ **350,000 token/วัน** [1] ตัวเลขนี้น่าจะต่างกันไปตามโมเดลแต่ละตัว (ไม่มีเอกสารทางการยืนยันตัวเลขของโมเดลอื่นนอกจาก Gemini)

## User Guide (Step-by-Step)

1. **สมัคร/ยืนยันตัวตน** — ถ้ามีบัญชี TK Park (e-Member, Standard, Plus) หรือ OKMD e-member อยู่แล้ว ใช้ username/password เดิม login ที่ `playground.okmd.or.th` ได้ทันที ถ้ายังไม่มี สมัครฟรีที่ `mytk.tkpark.or.th` ก่อน หรือเลือก login ตรงผ่านแอป **ThaiD** ของภาครัฐ (ใช้ข้อมูลบัตรประชาชนยืนยันตัวตน) [2][9]
2. **เลือกโมเดล** — จากหน้า dashboard เลือกโมเดล (Gemini, Claude Sonnet, GPT, DeepSeek, Grok ฯลฯ) หรือใช้ Compare & Contrast เพื่อยิงคำถามเดียวไปหลายโมเดลพร้อมกัน
3. **ลองสร้างเว็บแอป** — พิมพ์คำสั่งอธิบายเว็บที่ต้องการ (เช่น "ช่วยทำเว็บร้านกาแฟสวยๆ ให้หน่อย") กด **deploy** มุมขวาบนเพื่อทดสอบ แชร์ลิงก์ให้เพื่อนเล่น หรือดาวน์โหลด source code ไปใช้ต่อ
4. **ลอง TTS** — สั่งให้ AI ใส่ปุ่มอ่านออกเสียง เลือกความเร็ว และดาวน์โหลดเป็น MP3 ในเว็บแอปที่สร้าง
5. **ลองสร้างภาพ** — เปลี่ยนไปโมเดลที่รองรับ image generation (เช่น Gemini 3.5 Flash) สั่งสร้างภาพปก พร้อมกำหนด composition และข้อความในภาพ
6. **เช็ค quota** — ไปที่ Setting เพื่อดูว่าแต่ละโมเดลใช้ token ไปเท่าไหร่แล้วในวันนี้ ป้องกันโควตาหมดกลางทาง
7. **ใช้ API key เชื่อมแอปตัวเอง** — จากหน้า developer section, generate API key แล้วยิง request ทดสอบผ่าน `curl` ก่อนต่อเข้าแอปพลิเคชันจริง

## Caveats / Limits

- **"3 ฟีเจอร์เด็ด" ที่ข่าวพูดถึง ไม่ใช่ 3 ฟีเจอร์ในตัว Playground เดียว** — จริงๆ คือ 3 บริการคนละตัว (Playground / Knowledge Portal / Corporate) อย่าสับสนว่า Playground มีแค่ 3 อย่าง เพราะจากคลิปสาธิตพบฟีเจอร์ในตัว Playground เองมากกว่านั้น (chat, web-app builder, TTS, image gen, API) [4]
- **โควตาต่อวันจำกัดจริง** — ต้องวางแผนการใช้งาน โดยเฉพาะถ้าจะสร้างเว็บแอปหรือทดสอบ API ต่อเนื่องยาวๆ ในวันเดียว อาจชนโควตาก่อนจบงาน
- **งบประมาณกับความคุ้มค่า** — ข้อวิจารณ์ในสภาว่าโครงการนี้ (2.4 ล้านบาท) เทียบกับ TH-AI Passport (1,621 ล้านบาท) ยังไม่มีบทสรุปทางการจากหน่วยงานตรวจสอบ [6] — เป็นประเด็นที่ควรติดตามต่อ ไม่ใช่ fact ปิดเรื่องแล้ว
- **ข้อมูล privacy/data retention ของ prompt ที่ส่งเข้า Playground** ไม่มีการเปิดเผยรายละเอียดในแหล่งข่าวที่ตรวจสอบได้ — ถ้าจะใช้ทดสอบ business logic หรือข้อมูลอ่อนไหว ควรระวังเช่นเดียวกับ third-party AI gateway ทั่วไป
- **โมเดลที่ให้ใช้อาจไม่ใช่เวอร์ชันล่าสุดตลอดเวลา** — ชื่อรุ่นที่ปรากฏในคลิป (เช่น Gemini 3.5 Flash, Sonnet 5) เป็นสถานะ ณ วันที่ทดสอบ (1 พ.ค. 2569) อาจเปลี่ยนแปลงตามการอัปเดตของ OKMD

## Key Takeaways

- OKMD AI Playground รวม Gemini, GPT, Claude Sonnet, DeepSeek, Grok, Meta AI, Perplexity ฯลฯ ไว้ในที่เดียว ใช้ฟรีจริง ตรวจสอบได้จากทั้งข่าวและคลิปสาธิต
- เข้าใช้งานผ่านบัญชี TK Park/OKMD e-member เดิม หรือ login ตรงผ่านแอป ThaiD — ไม่ใช่แค่ chat แต่มี web-app builder (deploy ได้จริง), TTS, image generation, และ API key สำหรับนักพัฒนา
- โควตาฟรีราว 350,000 token/วันสำหรับ Gemini (ตัวเลขต่อโมเดลอื่นไม่ยืนยันจากเอกสารทางการ)
- "3 ฟีเจอร์เด็ด" ในข่าวคือ 3 บริการคนละตัว (Playground/Knowledge Portal/Corporate) ไม่ใช่ 3 ความสามารถใน Playground เดียว
- งบพัฒนาต่ำมาก (2.4 ล้านบาท) เทียบโครงการ AI ภาครัฐอื่นที่ใช้งบสูงกว่าหลักพันล้าน — เป็นประเด็นวิจารณ์เรื่องความคุ้มค่าที่ยังไม่มีบทสรุป
- เหมาะเป็นจุดเริ่มต้นฟรีสำหรับคนไทยที่อยากลองใช้ AI หลายค่ายโดยไม่ต้องผูกบัตรเครดิต แต่ควรระวังเรื่อง data privacy เหมือนใช้ third-party AI gateway ทั่วไป
